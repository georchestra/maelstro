# Prise en main

1. Recherchez un jeu de données dans le catalogue source. Cochez **Inclure les
   données moissonnées** pour les inclure dans la recherche.
2. Choisissez une plateforme de destination.
3. Sélectionnez les éléments à copier : métadonnées, couches liées et styles.
4. Envoyez le formulaire pour afficher l'aperçu, puis confirmez pour lancer la
   synchronisation.
5. Consultez le résultat des opérations. Les exécutions précédentes sont
   disponibles dans la vue des journaux.

Le catalogue source et les destinations sont définis dans la configuration du
serveur et ne peuvent pas être modifiés depuis le formulaire.
