Maelstro propose deux vues principales :

- **Synchronisation** : rechercher dans le catalogue source, choisir une
  destination et les éléments à copier, puis prévisualiser et lancer la copie.
- **Journaux** : parcourir les synchronisations précédentes, paginer les
  résultats et développer une exécution pour consulter ses opérations.

## Options de synchronisation

Le formulaire de synchronisation permet de :

- Rechercher dans le GeoNetwork source configuré, avec ou sans les données
  moissonnées.
- Choisir une destination configurée.
- Inclure ou exclure séparément les métadonnées, les couches GeoServer liées et
  leurs styles.

Envoyez le formulaire pour prévisualiser les ressources et opérations avant de
confirmer la copie. Les options disponibles dépendent du jeu de données et des
serveurs configurés.

## Démarage de la synchronisation

1. Recherchez un jeu de données dans le catalogue source. Cochez **Inclure les
   données moissonnées** pour les inclure dans la recherche.
2. Choisissez une plateforme de destination.
3. Sélectionnez les éléments à copier : métadonnées, couches liées et styles.
4. Envoyez le formulaire pour afficher l'aperçu, puis confirmez pour lancer la
   synchronisation.
5. Consultez le résultat des opérations. Les exécutions précédentes sont
   disponibles dans la vue des journaux.

Le catalogue source et les destinations sont définis dans la configuration du
serveur et ne peuvent pas être modifiés depuis le formulaire.
