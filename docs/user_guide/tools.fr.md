# Options de synchronisation

Le formulaire de synchronisation permet de :

- Rechercher dans le GeoNetwork source configuré, avec ou sans les données
  moissonnées.
- Choisir une destination configurée.
- Inclure ou exclure séparément les métadonnées, les couches GeoServer liées et
  leurs styles.

Envoyez le formulaire pour prévisualiser les ressources et opérations avant de
confirmer la copie. Les options disponibles dépendent du jeu de données et des
serveurs configurés.
