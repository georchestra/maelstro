# Rédiger la documentation

Le site utilise MkDocs Material. Les pages sont écrites en Markdown dans
`docs/` et la navigation est configurée dans `mkdocs.yml`. Utilisez des liens
relatifs entre les pages et placez les images dans le dossier `images/`
approprié.

Consultez le [Guide Markdown](https://www.markdownguide.org/basic-syntax/) pour
voir des exemples de syntaxe.
