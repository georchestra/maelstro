# Préparer le déploiement

Choisissez le fichier Compose correspondant à votre installation :

- Autonome : `docker-compose-solo.yml`
- Avec geOrchestra : `docker-compose-geOrchestra.yml`
- Développement : `docker-compose-dev.yml`

Le [README](../../../README.md) explique comment sélectionner un fichier
Compose. Pour geOrchestra, appliquez d'abord la configuration du datadir et de
la passerelle décrite dans [`config/HOWTO.md`](../../../config/HOWTO.md).
