# Prepare a deployment

Choose the Compose file for your setup:

- Standalone: `docker-compose-solo.yml`
- With geOrchestra: `docker-compose-geOrchestra.yml`
- Development: `docker-compose-dev.yml`

The root [README](../../../README.md) describes how to select a Compose file.
For geOrchestra, first apply the datadir and gateway configuration described in
[`config/HOWTO.md`](../../../config/HOWTO.md).
