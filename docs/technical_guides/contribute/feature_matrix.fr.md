# Fonctionnalités

| Fonctionnalité | Disponibilité |
|---|---|
| Rechercher dans une source GeoNetwork configurée | Oui |
| Copier les métadonnées vers une destination | Au choix pour chaque copie |
| Copier les couches GeoServer liées et leurs styles | Au choix pour chaque copie |
| Appliquer des transformations XSL configurées | Facultatif |
| Prévisualiser les opérations et consulter les résultats | Oui |
| Parcourir l'historique des synchronisations | Si la journalisation en base est configurée |
| Déploiement autonome ou avec geOrchestra | Oui |
