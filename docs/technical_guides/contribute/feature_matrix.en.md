# Features

| Feature | Availability |
|---|---|
| Search a configured GeoNetwork source | Yes |
| Copy metadata to a configured destination | Optional per run |
| Copy linked GeoServer layers and styles | Optional per run |
| Apply configured XSL transformations | Optional |
| Preview operations and inspect results | Yes |
| Browse synchronization history | When database logging is configured |
| Standalone or geOrchestra deployment | Yes |
